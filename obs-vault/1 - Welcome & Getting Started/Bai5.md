## Công Cụ Cần Thiết Cho Khóa Học ASP.NET Core MVC

### Yêu Cầu Công Cụ
- **Mục tiêu**: Chuẩn bị các công cụ cần thiết để lập trình và phát triển ứng dụng ASP.NET Core MVC.
- **Danh sách công cụ**:
  - **.NET SDK**:
    - Cài đặt .NET 7 hoặc .NET 8 (tùy thuộc vào thời điểm học).
    - Nếu .NET 8 đang ở giai đoạn xem trước (preview), hãy tải phiên bản preview để theo kịp khóa học.
  - **Visual Studio 2022**:
    - Yêu cầu Visual Studio 2022 cho .NET 7.
    - Nếu sử dụng .NET 8, tải phiên bản Visual Studio 2022 Preview để hỗ trợ phiên bản .NET mới nhất.
  - **SQL Server và SQL Server Management Studio (SSMS)**:
    - Sử dụng SQL Server làm cơ sở dữ liệu.
    - SSMS để quản lý và viết các câu lệnh SQL.

### Hướng Dẫn Cài Đặt
- **Phiên bản .NET**:
  - Ưu tiên cài đặt .NET 8 (preview) nếu muốn sử dụng phiên bản mới nhất.
  - Nếu không, .NET 7 là lựa chọn ổn định và tương thích với khóa học.
- **Visual Studio**:
  - Đảm bảo cài đặt Visual Studio 2022 (hoặc Preview cho .NET 8).
  - Cấu hình để hỗ trợ phát triển ASP.NET Core.
- **SQL Server**:
  - Cài đặt SQL Server và SSMS để quản lý cơ sở dữ liệu.
  - SSMS giúp thực hiện các câu lệnh SQL cơ bản như SELECT, INSERT, UPDATE, DELETE.

### Ghi Chú Thêm
- **Tài liệu tham khảo**:
  - Các liên kết tải công cụ sẽ được cung cấp trong phần mô tả của video khóa học.
- **Khuyến nghị**:
  - Kiểm tra phiên bản .NET trước khi bắt đầu để đảm bảo tương thích với Visual Studio.
  - Cài đặt đầy đủ các công cụ trước khi bắt đầu để tránh gián đoạn trong quá trình học.
